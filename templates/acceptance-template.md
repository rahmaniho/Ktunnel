# قالب پذیرش (G5)

> تنها فرمی که `reality-checker` امضا می‌کند. تا وقتی این فرم پر نشده، کار
> «تمام» نیست. پیش‌فرض تصمیم **«نیاز به کار»** است؛ تأیید باید به دست بیاید.

---

```markdown
---
gate: G5
feature: <نام قابلیت یا نسخه>
task: projects/<نام>/tasks/<فایل>
date: <YYYY-MM-DD>
decided_by: reality-checker
decision: <آماده | نیاز به کار | بازدارنده>
---

## ۱. تطبیق معیار پذیرش

| # | معیار (از تسک) | شاهد | نتیجه |
| --- | --- | --- | --- |
| ۱ | <معیار> | `reports/.../evidence-1.log` | ✅ / ❌ / ⚠️ |
| ۲ | <معیار> | <لینک> | ✅ |

**قاعده:** هر ✅ باید یک مسیر شاهد داشته باشد. شاهد «شفاهی» یا «در جلسه دیدم»
قبول نیست.

## ۲. دروازه‌های وابسته

| دروازه | وضعیت | شاهد |
| --- | --- | --- |
| G3 اثبات | 🟢 / 🔴 | `reports/<...>` |
| G4 امنیت | 🟢 / 🔴 | `reports/security/<...>/SUMMARY.md` |

اگر G4 باز نیست، این فرم نمی‌تواند «آماده» باشد — حتی اگر همهٔ معیارهای
قابلیت پوشش داده شده باشند.

## ۳. بررسی‌های لبه

| بررسی | نتیجه | شاهد |
| --- | --- | --- |
| حالت‌های خطا (ورودی خالی/بزرگ/غلط) | | |
| نقش/مجوز کم‌دسترس | | |
| دادهٔ موجود و مهاجرت | | |
| رفتار در قطع شبکه/سرویس وابسته | | |
| دسترس‌پذیری (اگر UI) | | |
| بار/کارایی در مسیر داغ | | |

## ۴. ریسک‌های پذیرفته‌شده

| ریسک | مالک پذیرش | مهلت بازبینی | چرا الان پذیرفته می‌شود |
| --- | --- | --- | --- |
| | | | |

**ریسک بدون مالک، پذیرفته‌شده نیست** — یعنی «نیاز به کار».

## ۵. تصمیم

### آماده
> همهٔ معیارها شاهد دارند، G3 و G4 بسته‌اند، و ریسک بازِ بی‌مالک وجود ندارد.

### نیاز به کار
> فهرست ایراد با بازتولید:

| # | ایراد | گام بازگشت | مالک |
| --- | --- | --- | --- |
| ۱ | | گام ۳ / ۲ / ۱ | |

### بازدارنده
> مشکل ساختاری است، نه ایراد قابل اصلاح. دلیل:

## ۶. چه چیزی این فرم را تأیید **نمی‌کند**

- این فرم «کیفیت کلی محصول» را تأیید نمی‌کند؛ فقط این قابلیت را.
- تأیید G5 جای G4 را نمی‌گیرد.
- این فرم جایگزین یادداشت انتشار نیست.
```

## آزمون واقع‌گرایی

قبل از پر کردن، سه سؤال از خودتان بپرسید:

1. اگر این تغییر فردا در محیط واقعی خطا بدهد، **کدام شاهد** را نداشتم؟
2. آیا شاهدها را **خودم** دیدم یا کسی گفت؟
3. آیا می‌توانم این قابلیت را بدون کمک نویسندهٔ آن اجرا کنم؟

اگر پاسخ سؤال ۲ «کسی گفت» است، شاهد را ببینید. اگر پاسخ سؤال ۳ «نه» است،
یا مستند ناقص است یا کار ناقص.
