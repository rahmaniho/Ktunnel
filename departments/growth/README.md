# بخش رشد

مسئول: **از محصول آماده تا کاربر واقعی — با آزمایش، نه با حدس.**

## مأموریت

رشد در این آژانس یعنی «حلقه‌ای که خودش را تغذیه می‌کند»، نه «کمپین یک‌باره».
هر فعالیت رشد باید یک فرضیه، یک متریک، و یک شرط توقف داشته باشد. محتوایی که
نمی‌توان اثرش را سنجید، هزینه است نه سرمایه‌گذاری.

## اعضای تیم و مرز نقش‌ها

| شناسه | نقش در این بخش | وقتی صدایش می‌زنیم | خروجی |
| --- | --- | --- | --- |
| `growth-hacker` | مالک آزمایش رشد | افت قیف، ورودی جدید، حلقهٔ بازگشت | طرح آزمایش + متریک |
| `seo-specialist` | مالک جست‌وجوی ارگانیک | ساختار محتوا، کاهش ترافیک جست‌وجو | برنامهٔ سئو + تغییر فنی |
| `content-creator` | مالک تولید محتوا | تقویم محتوا، صفحهٔ فرود | محتوا + تقویم |
| `social-media-strategist` | مالک انتشار اجتماعی | راه‌اندازی کانال، تقویم انتشار | استراتژی کانال |
| `pr-communications-manager` | مالک روایت عمومی و بحران | انتشار مهم، رخداد عمومی، بیانیه | پیام + بیانیه |
| `product-manager` | مالک هم‌ترازی با محصول | تعارض پیام و واقعیت محصول | تأیید یا اصلاح |

**مرز با محصول:** بخش رشد **چه چیزی بگوییم** را طراحی می‌کند؛ `product-manager`
تأیید می‌کند که آن «چه چیزی» واقعاً در محصول وجود دارد. وعدهٔ قابلیتی که
ساخته نشده، ممنوع است — حتی به‌عنوان «به‌زودی».

## دروازه‌ها

| دروازه | شرط عبور | شاهد |
| --- | --- | --- |
| G0 (مشترک) | فرضیهٔ رشد با متریک و شرط توقف | طرح آزمایش |
| G5 (مشترک) | هر ادعای عمومی با محصول مطابقت دارد | تأیید `product-manager` |

## قرارداد ورودی

از `departments/product`:

- محصول یا قابلیت قابل استفاده (نه طرح روی کاغذ)
- مخاطب هدف و جایگاه‌یابی
- متریکی که «موفقیت» را تعریف می‌کند

## قرارداد خروجی

به `departments/product`:

- نتیجهٔ آزمایش: چه چیزی کار کرد، چه چیزی نه، با عدد
- محتوای منتشرشده + محل انتشار + تاریخ
- درس‌های قابل استفاده در تکرار بعدی

## الگوی کار

```
فرضیه ──► growth-hacker (طرح آزمایش)
             │
             ├──► seo-specialist ──► content-creator
             └──► social-media-strategist ──► pr (در صورت نیاز)
                              │
                              ▼
                       سنجش ──► یادگیری ──► فرضیهٔ بعدی
```

## ضدالگوها

- کمپین بدون متریک.
- «وایرال شویم» به‌عنوان استراتژی.
- وعدهٔ قابلیتِ نساخته‌شده برای جذب.
- تولید محتوا بدون بررسی `seo-specialist` روی ساختار.
- پیام بحرانی که `pr-communications-manager` ندیده.
