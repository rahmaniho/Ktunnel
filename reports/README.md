# گزارش‌ها

> آرشیو شواهد. هر ادعای «انجام شد» در آژانس باید اینجا شاهد داشته باشد.

## چیدمان

```
reports/
├── <تاریخ>-<قابلیت>/          # شواهد یک تحویل (G3/G5)
│   ├── SUMMARY.md             # چه چیزی تحویل شد، تصمیم
│   ├── tests.log              # خروجی واقعی اجرا
│   └── screenshots/
├── security/
│   └── <تاریخ>-<دامنه>/       # خروجی جریان security-audit
│       ├── SCOPE.md
│       ├── FINDINGS.md
│       ├── PLAN.md
│       └── SUMMARY.md
├── release/
│   └── <نسخه>/NOTES.md        # یادداشت انتشار
└── bugs/
    └── <تاریخ>-<عنوان>.md     # گزارش باگ و ریشه‌یابی
```

## قواعد

| قاعده | دلیل |
| --- | --- |
| نام پوشه با تاریخ ISO شروع می‌شود (`2026-11-04-...`) | مرتب‌سازی زمانی بدون تلاش |
| شاهد خام ذخیره می‌شود، بدون ویرایش | شاهد ویرایش‌شده شاهد نیست |
| هر گزارش یک `SUMMARY.md` دارد | خوانندهٔ بعدی از خلاصه شروع می‌کند |
| راز، توکن، و دادهٔ شخصی در گزارش نمی‌آید | گزارش‌ها در گیت می‌مانند |
| گزارش‌های قدیمی حذف نمی‌شوند | تاریخ تصمیم‌ها بخشی از حافظه است |

## وضعیت فعلی

هیچ گزارشی ثبت نشده. اولین گزارش با اولین تحویل از
`workflows/feature-development.md` ساخته می‌شود.
