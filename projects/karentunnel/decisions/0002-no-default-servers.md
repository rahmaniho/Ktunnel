# ADR-0002 — هیچ سرور پیش‌فرض یا «توصیه‌شده‌ای» وجود ندارد

```yaml
id: ADR-0002
date: 2026-11-04
status: پذیرفته
deciders: product, security
supersedes:
```

## زمینه

اپ‌های VPN معمولاً فهرستی از سرور با پرچم کشور و «کمترین پینگ» نشان می‌دهند.
این الگو کاربر را راضی می‌کند، اما سه مشکل دارد: سرورها باید از جایی بیایند،
پینگ باید از جایی بیاید، و اگر ندهیم کاربر فکر می‌کند اپ خراب است.

## تصمیم

**انتخاب کردیم که** هیچ سرور پیش‌فرضی نداشته باشیم و هیچ عددی که خودمان
تولید نکرده‌ایم نشان ندهیم. تنها راه اضافه کردن سرور، چسباندن یک `.conf`
واقعی است.

`ServerSummary` **هیچ فیلدی برای پینگ یا تأخیر ندارد** — نه اینکه خالی رها شده
باشد، بلکه وجود ندارد. یعنی نمی‌شود بعداً «تصادفی» پر شود.

## گزینه‌های ردشده

| گزینه | چرا رد شد |
| --- | --- |
| سرور رایگان پیش‌فرض | جایی برای جمع‌آوری داده می‌سازد؛ و کاربر نمی‌داند چه کسی ترافیکش را می‌بیند. |
| پینگ ساختگی/تصادفی | دروغ. کاربر بر اساس آن تصمیم می‌گیرد. |
| پینگ واقعی به endpoint | نیازمند بستهٔ ICMP یا دست‌دادن واقعی؛ ICMP در اندروید مجوز خام لازم دارد و دست‌دادن هم قبل از اتصال ممکن نیست. مقدار «تخمینی» هم همان دروغ است با اسم دیگر. |
| فهرست کشورها | بدون سرور، فقط تزئین است. |

## پیامدها

- کاربر تازه‌وارد صفحهٔ خالی می‌بیند و باید `.conf` داشته باشد. این **عمدی**
  است و متن خالی این را توضیح می‌دهد.
- اپ نمی‌تواند «راحت» به نظر برسد؛ می‌تواند صادق به نظر برسد.
