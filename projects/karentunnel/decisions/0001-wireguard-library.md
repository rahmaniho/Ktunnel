# ADR-0001 — استفاده از کتابخانهٔ رسمی WireGuard به‌جای پیاده‌سازی خودمان

status: پذیرفته

## زمینه

اپ باید یک تونل VPN بسازد. مسیرهای ممکن: پیاده‌سازی پروتکل، پیوند دادن به
باینری `wg-quick`، یا استفاده از کتابخانهٔ منتشرشدهٔ رسمی.

رمزنگاری چیزی نیست که به‌صورت واگرا (side project) درست از آب دربیاید.

## تصمیم

**انتخاب کردیم که** از `com.wireguard.android:tunnel` نسخهٔ `1.0.20260102`
استفاده کنیم و صفر خط رمزنگاری خودمان بنویسیم.

## گزینه‌های ردشده

| گزینه | چرا رد شد |
| --- | --- |
| پیاده‌سازی Curve25519/ChaCha20-Poly1305 | یک خطا در مدیریت nonce یا مقایسهٔ کلید = شکست کامل امنیتی. تخصص و زمان لازم دارد که این پروژه ندارد. |
| اجرای `wg` با `Runtime.exec` | نیازمند باینری root/shell و مجوزهای غیرممکن؛ با مدل مجوز اندروید نمی‌سازد. |
| فورک کردن سورس کتابخانه | بار نگهداری امنیتی؛ وصله‌های امنیتی upstream را از دست می‌دهیم. |
| `1.0.20260315` (نسخهٔ جدیدتر) | **هرگز به Maven منتشر نشده.** تلاش برای استفاده، بیلد را شکست؛ جزئیات در `ci/wireguard-artifact-probe.md`. |

## پیامدها

- وابستگی به یک آرتیفکت خارجی. اگر منتشر نشود، ما گیر می‌کنیم.
- نسخه pin شده است؛ ارتقا تصمیم آگاهانه است، نه خودکار.
- مسئلهٔ مجوز: خود کتابخانه Apache-2.0 است، اما بیلد از سورسش GPLv2 است.
