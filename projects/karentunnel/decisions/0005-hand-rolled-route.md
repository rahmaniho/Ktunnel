# ADR-0005 — ناوبری دست‌نویس به‌جای Navigation-Compose

## زمینه

چهار صفحه داریم: داشبورد، سرورها، تنظیمات، عیب‌یابی. Navigation-Compose
کتابخانهٔ استاندارد است، اما deep link، الگوی back stack و یک وابستگی اضافه
می‌آورد که باید pin شود.

## تصمیم

**انتخاب کردیم که** یک `enum class Route` چهارمقداری و یک `when` در
`KarenTunnelNavHost` داشته باشیم.

## گزینه‌های ردشده

| گزینه | چرا رد شد |
| --- | --- |
| Navigation-Compose | وابستگی اضافه برای چهار صفحه؛ deep link هیچ کاربردی در اپ VPN ندارد و سطح حملهٔ اضافه است. |
| چند `Activity` | گذر بین Activity ها سنگین‌تر است و state را باید دستی منتقل کرد. |
| Fragment | پروژه کاملاً Compose است؛ بازگشت به Fragment عقب‌گرد است. |

## پیامدها

- دکمهٔ Back سیستم باید دستی مدیریت شود (`BackHandler`).
- اگر صفحهٔ پنجمی اضافه شود، این تصمیم باید دوباره بررسی شود — آستانه در حدود
  شش صفحه است، نه بیشتر.
