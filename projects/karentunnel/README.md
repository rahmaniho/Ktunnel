# KarenTunnel

یک اپ VPN اندروید شخصی، با Kotlin و Jetpack Compose، رابط فارسی راست‌به‌چپ،
بر پایهٔ **کتابخانهٔ رسمی WireGuard**.

> **قاعدهٔ بنیادین:** برنامه هرگز وضعیتی را که نمی‌تواند اثبات کند نشان نمی‌دهد.
> «متصل» یعنی سه شرط هم‌زمان برقرار باشد؛ وگرنه «متصل، بدون تأیید» است.

این جدول عمداً بالای README است. کدی که کامپایل می‌شود و تست واحدش می‌گذرد،
هنوز یک VPN کارآمد نیست.

## این برنامه چه کار می‌کند

- **تونل WireGuard** با کتابخانهٔ رسمی `com.wireguard.android:tunnel`.
  هیچ رمزنگاری‌ای خودمان نساخته‌ایم.
- **کلید روی دستگاه**: کلید خصوصی یا از فایل `.conf` خودتان می‌آید یا ساخته
  می‌شود؛ با **Android Keystore** رمزنگاری می‌شود و در `filesDir` می‌ماند.
- **رابط فارسی RTL** با Compose: داشبورد، سرورها، تنظیمات، عیب‌یابی.
- **سرویس پیش‌زمینه** تا تونل با بستن اپ قطع نشود.
- **عیب‌یابی سه‌سطحی**: تأییدشده / احتمالی / نامشخص.

## این برنامه چه کار **نمی‌کند**

- ❌ **سرور نمی‌سازد و نمی‌فروشد.** هیچ سرور پیش‌فرضی وجود ندارد. باید فایل
  `.conf` خودتان را وارد کنید. اگر سرور ندارید، این اپ برای شما نیست.
- ❌ **ادعای عبور از سانسور نمی‌کند.** هیچ مکانیزم دور زدن فیلترینگ در آن نیست.
  اگر شبکه‌ای ترافیک WireGuard را مسدود کند، این اپ هم کار نمی‌کند.
- ❌ **ادعا نمی‌کند فیلترینگ را «شناسایی» می‌کند.** تشخیص حداکثر می‌تواند
  بگوید «نشانه‌ها با یک فرضیه سازگارند».
- ❌ **آمار جعلی ندارد.** آمار ترافیک از `backend.getStatistics()` می‌آید، نه
  از یک شمارندهٔ ساختگی.
- ❌ **وضعیت جعلی ندارد.** «متصل» فقط با اثبات.

## نصب

### از APK

```bash
# از artifact اجرای CI دانلود کنید:
# karentunnel-debug-apk  (یا karentunnel-release-apk-ci-signed)
adb install -r karentunnel-debug.apk
```

> ⚠️ APK دیباگ با کلید debug اندروید امضا شده. artifact release با کلید
> **موقت CI** امضا می‌شود. هیچ‌کدام برای توزیع عمومی مناسب نیستند.

### از سورس

```bash
git clone https://github.com/rahmaniho/Ktunnel
cd Ktunnel/projects/karentunnel

# JDK 17 و Android SDK 36 لازم است
./gradlew assembleDebug
./gradlew testDebugUnitTest
./gradlew lintDebug
```

## استفاده

۱. **سرورها** ← «افزودن سرور» ← محتوای فایل `.conf` را بچسبانید.
۲. سرور را انتخاب کنید.
۳. در داشبورد دکمهٔ اتصال را بزنید؛ اندروید مجوز VPN می‌خواهد.
۴. وضعیت را ببینید:
   - **سبز «متصل»** — هر سه شرط اثبات برقرار است.
   - **کهربایی «متصل، بدون تأیید»** — تونل بالاست اما دست‌دادن دیده نمی‌شود.
   - **قرمز** — خطا با دلیل مشخص.
۵. اگر چیزی کار نکرد: **عیب‌یابی** ← «اجرای آزمون».

## قالب فایل پیکربندی

```ini
[Interface]
PrivateKey = <کلید خصوصی شما>
Address = 10.66.0.2/32
DNS = 10.66.0.1

[Peer]
PublicKey = <کلید عمومی سرور>
AllowedIPs = 0.0.0.0/0
Endpoint = vpn.example.com:51820
```

**پیکربندی‌هایی که رد می‌شوند** (عمداً، برای جلوگیری از نشتی):

- بدون خط `DNS`
- نشانی IPv6 بدون مسیر `::/0`
- همهٔ DNSها IPv6 بدون تونل IPv6
- بیش از ۴ سرور DNS
- کلید نامعتبر یا تکراری
- کلید ناشناخته (typo در `AllowedIPs` نباید بی‌صدا نادیده گرفته شود)
